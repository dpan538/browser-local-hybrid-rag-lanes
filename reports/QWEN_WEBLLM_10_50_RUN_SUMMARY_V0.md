## Interpretation

This run supports the paper framing that the central question is not simply
whether a local 0.8B-class model can answer, but which answer lanes should avoid
generation. C3 reduced Qwen invocations from 50/50 in C1 to 27/50 while also
removing the observed refusal-alignment failures.

The cleanest empirical finding from this run is:

```text
Adding deterministic refusal lanes improved contract compliance without
requiring Qwen generation for refusal-required rows.
```

The strongest ablation contrast is C2 versus C3. C2 already has deterministic
source/rights rendering, but lacks deterministic refusal; it retains the same
15 refusal failures as C1. C3 adds deterministic refusal and reduces failures to
0 on the 50-query fixture.

## Non-Claims

This run does not claim:

- source metadata correctness;
- user-perceived usability;
- statistically stable P95 latency;
- superiority over a same-scale comparison model;
- that deterministic lanes are generated by Qwen.

The run does support a next paper-facing analysis pass over refusal correctness,
Qwen invocation reduction, and hybrid-lane latency accounting.
